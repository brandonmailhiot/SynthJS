SynthJS

Web-native music DSL with live diagnostics, hover, and autocomplete.

Editor features:
  • 🔴 Errors and warnings highlighted inline as you type
  • 🔍 Hover any pitch, motif, or effect for details (frequency, signature, docs)
  • ⌨️ Press Ctrl+Space for context-aware completions
  • 📄 Doc comments (///) appear in hover and completion tooltips

Output is muted until first user gesture (browser policy). Click Play to allow audio.
